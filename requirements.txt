# 共享设备借用系统 · 运行依赖
#
# 安装：
#   python -m venv .venv
#   .venv/bin/pip install -r requirements.txt
#
# 版本策略：**全部锁定精确版本**。
#   本项目同时依赖 numpy（矩阵）、faiss-cpu（向量索引）、rank-bm25、jieba，
#   其中 faiss-cpu 是对 numpy 的 C ABI 编译的。放开版本范围后，
#   一次 `pip install -U numpy` 就会让 faiss 在 import 时报
#   "undefined symbol"，而且报错点在 faiss 内部，很难定位到是版本漂移。
#   升级时请整组一起升，并在升级后跑一遍 `.venv/bin/python -m unittest discover -s tests`。
#
# Python：**3.12+**（开发与验证环境为 3.13.12，CI 固定 3.12）。
#   下限由依赖决定，不是由语法决定：numpy 2.5.x 的 Requires-Python 就是 >=3.12，
#   在 3.11 上 pip 会直接找不到可安装的版本（本项目 CI 曾因此红过一次）。
#   语法上其实 3.10 就够（`X | None`、`datetime.astimezone()`），
#   所以如果哪天必须回到 3.11，改的是 numpy 那一组，不是代码。
